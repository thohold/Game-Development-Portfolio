Devlog 06.10.2026

Reloading, ammo, new rooms

Reloading and Ammo

Instead of having infinite ammo like before, I've now coded in an ammo system with reloading and ammo types. For now, light ammo is the only functional drop, since I only have one firearm implemented: the GK-73. But as I add more weapons, I will expand upon this functionality.

Light ammo now spawns in the world randomly on designated spawn points, giving players more reason to explore the map.

Event system

Instead of spawning enemies at random like most co-op horror games, I've made the foundations of something I call events. Each time you enter a new map, the map will roll a set number of events. These events determine which enemies spawn, which objectives are available, and in some cases which rooms spawn. Since I plan on making my enemies distinct, I want to control the amount of different enemies that spawn to avoid too much chaos.

Each event has a severity rating, which determines how strong and how many enemies spawn. I can also implement it so that new enemies and rooms are added as the severity increases.

For now, only the "moleflea infestation" event is implemented. But I plan to build the game around this system and already have some ideas.

New rooms

I've added 2 new room prefabs this week, in addition to cleaning up some prefabs so rooms connect more seamlessly. One of the new rooms I've added is an electrical room, which I plan to implement functionality for and an event for later.
