Project

Goblin Idle - Unity C# Prototype

Concept

My idea was to make an idle game, but one that is more interactive with smooth, satisfying progression. Players start with a simple tower, and enemies spawn into the arena at a slow pace. As the tower kills more and more enemies, the player can add more towers, upgrade the existing ones, and increase the rate at which enemies spawn and the loot they yield.

Source code can be found on the project page.

🎴 Cards

This is the core concept behind unlocking new towers and upgrades. As the player kills more and more enemies, they have a chance to drop cards. These cards can be upgrades, new towers, or new enemy types. Once a player has unlocked a card, they can use it to increase the rate at which they gather money.

Cards are split up into the classic RPG rarity system:

  • Common
  • Uncommon
  • Rare
  • Epic
  • Legendary

The chance of each respective rarity dropping is increasingly small. This adds some level of randomness to the progression.

Code: Cards are implemented using an abstract class and scriptable objects. New card behavior is easy to implement using abstraction and is easily tweakable for its respective towers using scriptable objects.

🏹 Towers

This is the player's way to kill enemies that spawn into the stage. All towers have their own respective stats, XP, and level. Once a tower levels up, you get a deck of 3 random upgrade cards to choose from among the available cards the player has unlocked. This adds another layer of randomness to the game.

Towers have different behaviors. Some target nearby enemies, some deploy traps, but they all have common stats, making the upgrade system work without needing to implement new cards for every tower.

The towers also visually update upon receiving upgrades, and you can mix and match different upgrades to get unique looks for your towers.

Code: Towers have a class structure consisting of the base tower class and the cannon. The Cannon.cs script specifies the behavior for each tower type, while the base structure class acts as an abstract class that holds the level and current XP. All towers are placed using currency and can be dragged out in a grid.

🧌 Enemies

  • Spawn from portals located around the map
  • Simple behavior; they run frantically around the map
  • Drops loot upon death that the player can use to upgrade or add new towers
  • Every enemy has different resistances; an elemental damage system is implemented

Code: Pathfinding is very simple so far; no search algorithms are used yet. They simply find a random position within bounds and run to that position. Once they reach it, they repeat the process.

⏱️ Idle game

The game currently doesn't have a win or loss condition. It simply progressively increases how many coins you get per second (or per wave of enemies).
